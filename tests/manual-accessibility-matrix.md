# CampusHub Manual Accessibility Verification Matrix

This checklist records verification evidence only. It does not override the
Frozen Product Specification or Blueprint.

## Evidence boundary

AUTOMATED:

- `npm run test:a11y` runs the existing canonical-mobile semantic and Axe gate.
- `npm run test:a11y:full` adds the verification spec on canonical-mobile,
  small-mobile, and desktop. It covers focus-not-obscured, text-spacing stress,
  the 320px gate, critical touch targets, selected desktop checks, and
  forced-colors emulation when the browser supports it.
- Automated checks can verify DOM semantics, geometry, state attributes,
  reflow, and the configured Axe rules. They cannot prove how NVDA, VoiceOver,
  or TalkBack announces the interface, nor can they certify the complete
  human experience.

MANUAL:

- MANUAL SCREEN-READER: NOT VERIFIED IN AGENT ENVIRONMENT.
- 200% BROWSER ZOOM: NOT VERIFIED IN AGENT ENVIRONMENT.
- 3G TIMING: NOT VALIDATED BY STATIC BYTE-BUDGET CHECK.
- Every entry below starts as `NOT RUN`. Change it only after a named tester
  executes the stated environment and journey.
- Recommended representative environments are Windows NVDA + Chrome and
  Firefox, VoiceOver + Safari on macOS/iOS where available, and TalkBack +
  Chrome on Android. The frozen authority does not require every environment
  for every pre-pilot run.

Axe passing is automated evidence only; this matrix is not a WCAG 2.2 AA
certification claim.
